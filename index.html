01 System Security · POSIX AST Interceptor

Stopping coding agents from breaking the system.

Security teams protect AI coding agents (Claude Code, Cursor, Copilot) with naive regexes like git commit or rm -rf. Attackers evade these with subshells $(), quotes, flag interleaving, and wrapper binaries. Guardrail Lab implements a zero-dependency AST tokenizer that analyzes the canonical AST and stops execution at the gate.

  • Guardrail Lab · Open Source

    Deterministic POSIX AST defense & 3D physical air-gap

    An interactive 3D WebGL simulator and deterministic AST tokenizer exposing the critical flaw in AI agent permission models. Intercepts 49 curated evasion vectors across 6 OWASP threat policies with zero runtime dependencies. Verified with an automated invariant test suite passing 21/21 assertions.

03 AI Engineering · Forensic Evaluation

An evaluation harness, engineered.

Generative AI and RAG agents frequently introduce subtle hallucinations and unsupported assertions that unit tests miss. Eval-Agent is an LLM-as-a-judge harness that extracts atomic claims from model outputs, audits each statement against source evidence, and arbitrates candidate answers head-to-head.

  1. 100%Pass rate across 20 curated benchmark test cases including adversarial hallucination traps and instruction adherence.
  2. < 900msForensic grading latency on Groq LLaMA-3.1 inference with claim-by-claim evidence audit trails.
  3. Pairwise A/BArbitration engine that pits two candidate agent responses against ground-truth docs and declares a grounded winner.
  4. Atomic ClaimsDeconstructs candidate text into atomic assertions labeled SUPPORTED, CONTRADICTED, or UNSUPPORTED.
  5. Span QuotingHighlights exact unsupported text spans in red and compiles structured JSON forensic audit reports.
